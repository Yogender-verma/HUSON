# HUSON – Holistic Urban Surplus Optimization Network

HUSON (Holistic Urban Surplus Optimization Network) is a platform designed to reduce food waste and support communities in need by connecting hotels, donors, and NGOs.

The platform enables hotels and individuals with surplus food to easily donate it, while NGOs can discover and collect available donations in real time. By creating a bridge between donors and organizations that distribute food to the needy, HUSON helps minimize food wastage and maximize social impact.

## Problem

Large amounts of edible food are wasted daily by hotels, restaurants, and events, while many people struggle with hunger. There is often no efficient system that connects food donors with organizations that can distribute the food quickly.

## Solution

HUSON provides a centralized network where:

* Hotels and individuals can list surplus food available for donation
* NGOs can view nearby donations and request pickups
* Food reaches people in need instead of being wasted

## Key Features

* Donation listing system for hotels and individuals
* NGO discovery and request system
* Simple and user-friendly interface
* Real-time connection between donors and NGOs
* Promotes sustainability and social responsibility

## Tech Stack

* HTML
* CSS
* JavaScript

## Vision

The goal of HUSON is to create smarter cities where surplus resources are efficiently redistributed to those who need them most, reducing waste and fighting hunger.
